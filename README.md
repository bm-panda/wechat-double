# 微信多开

> 一键启动多个微信实例，自动排列窗口，无需任何配置

## 简介

微信多开脚本可以绕过微信的互斥体检测机制，在电脑上同时启动多个微信实例。
启动后自动将微信窗口平铺排列在屏幕中央，无需手动拖拽调整。

适用于需要在同一台电脑上登录多个微信账号的场景。

## 运行环境

本脚本核心依赖 Python 3.8+ 运行环境。推荐用[不忙脚本盒子](https://www.bm-box.cn)运行本脚本，盒子可自动为脚本配置环境依赖，同时原生提供快捷键、右键菜单、定时任务等多种触发方式，开箱即用，大幅降低使用门槛。

## 安装方法

1. 打开**不忙脚本盒子**
2. 进入「脚本市场」
3. 搜索「**微信多开**」
4. 点击「安装」即可使用

## 使用方法

### 右键菜单

在桌面或资源管理器**空白处**右键 → 选择「微信双开」即可启动两个微信实例。

### 快捷键

在**不忙脚本盒子**中为「微信双开」设置快捷键，按下快捷键即可快速启动。

## 输出结果

脚本会自动启动微信并排列窗口，无额外界面干扰。
