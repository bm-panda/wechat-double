# 微信多开

> 一键启动多个微信实例的微信多开脚本，自动绕过互斥体检测并平铺排列窗口，无需任何配置，支持快捷键和右键菜单快速启动。

---

## 核心特性

- **一键多开**：同时启动多个微信实例，绕过微信互斥体限制
- **自动排列**：新窗口自动平铺排列在屏幕中央，无需手动拖拽
- **免配置**：自动检测微信安装路径，开箱即用
- **快速触发**：支持快捷键、右键菜单、卡片点击等多种方式一键启动

## 安装方法

本脚本的运行环境由"不忙脚本盒子"托管，建议仅通过盒子安装和使用本脚本。

> 前置条件：安装好 [不忙脚本盒子](https://www.bm-box.cn)

- 打开盒子 → **脚本市场** → 搜索 **「微信多开」**
- 点击「安装」

---

## 使用方式

- **右键启动**
  - 在桌面或资源管理器**空白处**右键 → 选择「微信多开」，即可启动两个微信实例
- **快捷键启动**
  - 在盒子里为「微信多开」设置全局快捷键，按下快捷键即可快速启动
- **直接启动**
  - 在盒子里点击脚本卡片即可运行

---

## 💡 使用提示

- 适合需要在同一台电脑上登录多个微信账号的场景，如工作号 + 生活号
- 默认启动 2 个实例，多开数量可在脚本内调整
- 微信需先安装（脚本自动从注册表检测安装路径）
